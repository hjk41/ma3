## 1. 设计原则

1. **与 v1 门户同壳**：`.topbar` / `.page-narrow` / `.card` / `.data` table；org 页不发明新导航范式。
2. **组织 vs 库分层清晰**：组织页管「人 + 库目录」；库页管「内容与授权」——避免在 org 页嵌 record 表格。
3. **容量可视化轻量**：CSS 进度条即可，无 chart 库；数字始终可见（accessibility）。
4. **危险操作克制**：移除成员 / 删除 grant 用 `confirm()` + `.btn-danger`；创建 team 用 primary，移除用 subtle。

## 10. 响应式

| 断点 | 行为 |
|------|------|
| ≥768px | stat 4 列；table 全列 |
| <768px | stat 2×2；table 隐藏「加入时间」等次要列；`.org-card-actions` 纵向堆叠 |

与 design/23 landing 相同：`@media (max-width: 768px)` 块追加，不新建 CSS 文件。

## 11. 空状态

| 页面 | 文案 + CTA |
|------|------------|
| `/ui/orgs/` 无 team | 「创建团队组织，与成员共享知识库」 |

## 12. 与 i18n / 主题衔接

- 所有可见字符串进 `zh-CN.json` / `en-US.json`
- 进度条 `aria-valuenow` / `aria-valuemax` 必填
- 不新增 icon font；org 卡 `[icon user]` 用文字或 Unicode 占位（• 或 👤 二选一，推荐 **不用 emoji**，用 `.org-card-icon` 圆形首字母）
