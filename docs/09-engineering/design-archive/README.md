# design-archive — decision summary index

> Chinese version: [README.zh.md](README.zh.md)

This directory **only keeps “decision summary” documents** per topic. Original process drafts (design sketches, review notes, visual mocks, etc.) have been compressed and removed.

- One `NN-<topic>-decisions.md` per topic, covering: background, decided items, explicit non-goals / rejected options, landing locations, and the list of historical drafts that were compressed away.
- Content here is **not contractual**: if it conflicts with formal docs, the layered documents under `docs/` and the ADRs win.
